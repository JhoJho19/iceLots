# Section 4.12 implementation and verification

Executed on 2026-10-13 in the project's connected Unity 6000.3.10f1 Windows Editor. Only section 4.12 was implemented. The generated mathematical data is in [Section412SimulationReport.md](Section412SimulationReport.md).

## Files and public API

All new code is in `Assets/_Project/Scripts/Tests/EditMode/`, using the existing test assembly and no new packages:

| File | Purpose |
|---|---|
| SlotSimulation.cs | Options, results, SplitMix64 RNG, Welford moments, headless runner and optional weekly adapter |
| SlotAnalyticalModel.cs | Independent exact line probabilities, real visible-window Scatter convolution and retrigger expectation |
| SlotSimulationReport.cs | Generated Markdown, deviations, uncertainty and capped jackpot expectation |
| SlotSimulationTests.cs | Deterministic/scripted regressions, smoke and explicit large validation entry point |
| Assets/Docs/Section412SimulationReport.md | Executed simulation output, generated by the explicit test |
| Assets/Docs/Section412Verification.md | This verification record |

Unity `.meta` files accompany the added assets. No existing production source, scene or configuration was edited by this work. Existing uncommitted section 4.11 changes were preserved.

`SlotSimulationRunner.Run(SlotRuntimeConfig config, SlotSimulationOptions options, IRandomSource reelRandom = null, IRandomSource jackpotRandom = null)` returns aggregate `SlotSimulationResult`. Options specify paid count, configured bet, seed, chain safety guard, jackpot mode, synthetic weeks, paid spins/week and UTC start. `SlotAnalyticalModel.Calculate(config)` returns independent expectations. `SlotSimulationReport.Markdown(result, out passed)` formats executed results.

The actual five serialized strips are loaded once through the existing provider. Every paid and free spin uses production `SlotEngine.Generate`; no grid generation, line evaluation or Scatter award algorithm is copied. Free queues finish before a paid return observation is recorded. BonusBet is the triggering configured bet; free returns are separate and have no paid wager. Guard exhaustion and checked coin/count overflow throw, preventing truncated or wrapped RTP results.

Test-only SplitMix64 uses explicitly specified unsigned integer operations with rejection sampling. Exact RNG vectors and measured seed-412 aggregates guard cross-runtime regressions. Jackpot uses seed XOR `D1B54A32D192ED03`; independent streams preserve reel results when jackpot is toggled. Production RNG settings remain unchanged. Existing `SystemRandomSource` sequence compatibility is limited to the same runtime implementation.

Uncapped jackpot uses production probability and Bernoulli sampler. Weekly mode additionally uses production `WeeklyJackpotService.Draw`, `ApplyWin` and `WeekAt`, with a private synthetic profile and supplied accepted times. It never calls SpinService, repositories, player saves or persistentDataPath. The main slot calculation has no GameSession. Synthetic allowance commits immediately because settlement failures are covered by separate application fixtures.

Results retain no individual outcomes. Monetary totals use checked Int64; Welford moments use doubles only for statistics. Histograms are bounded by configured payouts and the chain guard; weekly reporting retains one aggregate per configured week. Large validation is synchronous and temporarily occupies the editor, with no artificial waits.

Base RTP is 85.404745%; Free Spins contribution is 6.294165%. Theory derived from configuration is 85.6058559671% + 6.48305966016% = 92.0889156272%.

The million-run combined Slot RTP 95% interval is **[91.1222463267%, 92.2755736733%]**. SE is **0.294216159852 percentage points**; observed return variance is 8.6563148718. Absolute deviation is 0.390005627235 percentage points, about **1.33 SE**, statistically reasonable. The 100,000-spin Free Spins contribution is about 2.27 SE below theory and outside its approximate 95% interval; this is consistent with ordinary sampling fluctuations and passes the documented 5-SE investigation threshold. No mathematics was changed to force equality.

Paid Scatter counts 0..5: **589749, 328976, 72752, 8076, 438, 9**. P(3+) is **0.8523%**, versus theory **0.856%**; Wilson 95% interval **[0.834470387521%, 0.870507222637%]**. Initial FS awards total 70,044; 631 retriggers awarded 5,176 more spins; all 75,220 were executed. Longest chain 36; maximum chain payout 121,050. Winning paid spins 278,901; winning paid lines 465,477; maximum paid payout 116,000. Full frequency and payout tables are generated in the simulation report.

Uncapped jackpot: 1,000,000 eligible draws, **96 wins**, 9,600,000 coins, **0.96%** contribution, **92.65891%** combined return. Expected wins 100; wins SD about 10. This is the uncapped mathematical reference, not production long-term return.

Weekly schedule: **100 weeks × 10,000 paid spins**, starting Monday 2026-10-12 00:00 UTC, spins uniformly distributed inside each configured week, limit 1. **598,396 eligible draws, 63 wins**, 6,300,000 coins, **0.63%** contribution and **92.32891%** combined return. Analytical capped expectation is 63.2138953567 wins (SD 4.82223285367), or about **0.632138953567%** RTP. Every week has at most one paid jackpot. Exhausted weeks consume no further jackpot RNG. All jackpot trials are paid; Free Spins never participate.

Uncertainty is estimated from full paid-spin bonus chains for slot returns. Capped jackpot uncertainty uses independent week distributions, rather than treating capped paid trials as IID. Approximate confidence intervals are statistical estimates, not absolute correctness guarantees. Daily Bonus is excluded from RTP.
